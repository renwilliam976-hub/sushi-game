# 切图与接入说明

## 库存档位

三张食材素材板每行按“满 → 75% → 50% → 25% → 空”排列；第三张素材板的最后一行是补料动效物件。比例是视觉设计档位，不是按面积精确计量。

建议逻辑映射：库存为 0 用空图；0—25% 用低档；25—50% 用半档；50—75% 用较满档；75—100% 用满档。玩家只看到贴图变化。添加配料的三次、两次、一次点击升级，应改变制作逻辑和工作台状态，不在食材盒上追加进度。

## 切图原则

每件素材按实际外轮廓单独定裁切框，保留透明留边。不要直接按画布均分批量切片：人物表情、茶杯与酒杯成对图、UI 图标等存在不等宽内容。原图没有承诺严格帧对齐。

顾客锚点建议在双脚底部中心；柜台遮挡人物下半身由场景遮罩完成。食材盒以盒体底面中心对齐，五档换图时锁定盒口和底边。机器以底座中心对齐。卡车四状态锁定后轮接地点、车厢外轮廓与统一画布尺寸，避免换状态时抖动。

饭团架图已画出五个占用位；正式实现应把架体与饭团分层，才可逐个存取。茶和啤酒建议拆成空杯、液体、泡沫和前侧杯壁，再用裁切遮罩改变液面。清酒用瓶或壶的独立图直接拿取。

制作状态图的竹帘、海苔、米饭、配料目前合在一格内；动态添加配方时还需要把这些物体分层。自动化设备图用于确定外观，转轴、刀、盖子、蒸汽等活动部件尚未单独输出。

## 引擎内检查

在浅色与深色背景上检查透明边缘；统一线条粗细与视觉尺寸后再打图集。实际触控范围用独立热区设置，不直接沿着复杂贴图边缘。布局应适配 iPhone 横屏安全区，确保食材盒下方保留切配空间。

本包不提供虚构的精确裁切坐标、碰撞数据或导入成功记录。`asset-manifest.json` 中尺寸、透明通道、文件大小与校验值来自实际文件。
