## 先看这里

解压整个文件夹后，用电脑浏览器打开 `index.html`，即可离线浏览全部图片。拖动时间滑块，或点击“播放昼夜”，查看晨光、白天、黄昏、夜晚的缓慢过渡。点击缩略图查看完整 PNG。浏览时请保持目录结构不变；移动端文件管理器是否能直接打开本地 HTML 取决于所用应用。

## 昼夜怎么接入

店内背景固定，只有窗外层随营业时钟变化。四张窗外图按相邻时段交叉渐变，避免突然换天色。预览以 40 秒演示 07:00—22:00；正式游戏用自己的营业时长驱动。暂停、菜单和结算时冻结时钟。每日重新营业从晨光开始。具体关键帧与预览摆放坐标见 `09_Docs/day-night.json`。

## 与目前玩法一致的部分

- 库存由满、约 75%、约 50%、约 25%、空五档图表现；画面不显示剩余份数或加料进度条。
- 顾客与订单在上、食材盒居中，切配区在食材盒下方；左右安排补料、煮饭和饮料设备。
- 未买的机器不摆进营业场景；买到后再显示。新食材通过扩展食材位加入。
- 卡车车尾朝向店门，开厢补料；食材飞入盒子的轨迹由游戏动画实现，补满本波后卡车离开。
- 茶和啤酒用接取与液面变化表现；清酒直接拿取。饭团架按五个储存位设计。
- 装修价值、豪华值、售价加成及升级价格留在配置中，图片不写死数值。

## 素材状态

本包是第一版插图与素材底稿，包含独立单图和未切分的素材板。素材板的行列是内容排列提示，不能直接当成严格等尺寸精灵图集。接入前需要逐件切图、清理边缘、统一锚点与缩放，并补齐设备活动部件及过渡动画。PNG 是扁平图片，不包含 PSD 内部分层；透明背景不等同于可编辑分层。

表情图是造型参考，不能直接替换全身图的脸而不做对齐。卡车四张图是关键状态，不是完整开门动画。以前的整屏设计图用于讨论构图，不代表最终交互和数值。

所有原图保留原始尺寸；本包没有把小图放大充当高清图。
