# 决策记录

这是按本次游戏讨论整理的交接记录，不是聊天全文导出。用户后续修改优先于本文件。

## 用户明确要求

- 第一版主要安装在 iPhone；游戏主题为寿司店。
- 美术偏动画、简洁，避免太圆滑的廉价小游戏质感；第一套画风可以继续。
- 角色需要明显特点，加入男性女装 cosplayer、中年上班族、日本小学生及中国游客。
- 食材盒下面安排切配区。
- 食材库存与添加状态用贴图表现，不在食材盒上显示数值或添加进度；库存按每 25% 一档变化。
- 删除原有的三条容错提议；详见玩法文档。
- 添加配料初始点 3 次，可升级到 2 次和 1 次。
- 自动铺料、卷寿司机、快煮饭、装修豪华值与售价、菜单解锁、饮料、五个储存位的饭团、自动补料都是发展方向。
- 卡车倒着来，后厢对着店门，点击货物飞入盒子，补满一波自动离开。
- 茶和啤酒接取，清酒直接拿。
- 每位顾客有满意值；正确订单 100%，错误订单按满意值付钱，快出餐给小费。
- 通过实际需要自然引导购买升级。
- 窗外天色随营业时间缓慢变化。

## 还未决定

- 引擎与技术栈：本包没有预先选定 Unity、Godot 或 Swift/SpriteKit。
- 首版同时接待几位顾客，是否限关卡、无尽经营或混合模式。
- 托盘整单交付还是逐件交付。
- 精确寿司配方、菜单售价、错误订单评分权重与小费公式。
- 点击、煮饭、卷切、补料各动作耗时与消耗。
- 升级费用、解锁先后及装修豪华值。
- 存档时机、营业日长度和一天结束的条件。
- 音效、音乐及设备活动部件动画。

Codex 可在首个原型采用清楚标注的可配置默认值，不能把这些默认值写成用户已经同意的要求。
